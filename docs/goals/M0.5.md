# Second goal: M0.5, housekeeping and publish

Save this file as `docs/goals/M0.5.md`. Run it **before** M1. It fixes the identity, naming, tooling and remote setup so that M1 starts from a clean, published baseline.

---

## Before you run it (human checklist)

1. **GitHub repo:** `https://github.com/rkohnmn/racc-connect.git` must exist and be **empty** (created without a README, license or .gitignore). If it already has commits, the agent will stop rather than force anything.
2. **Credentials:** on the PC running Codex, confirm you can already push to GitHub (for example, Git Credential Manager is signed in as `rkohnmn`). The agent is told not to handle tokens or credential stores itself.
3. **Window of time:** installing `cargo-deny` compiles it from source and can take several minutes on a laptop.
4. The repo will be **public**. That is legal. With no license file, everyone may view and fork it through GitHub, but nobody else has the right to reuse the code. The goal records this honestly in the README and does not choose a license.
